## Decisions (Gabe, 2026-10-16/17)

clips launch on the next bar. Wake lock while playing or recording; REC chip
instead of refusing a switch. Main device is an Android tablet (tap + stylus);

## Recent User Requests & UX Priorities (Gabe, 2026-10-17)

1. **Persistent Media Player across pages/rooms**:
   - The media player (`#np`) must persist currently playing tracks without interruption when navigating from the Listening Room to the Studio (or vice versa).
   - `#np` should be the same unified object across all screens with seamless switching between audio sources (Shelf take from the shelf, live Studio tape mix, or live studio feed). The active playback and playhead position must continue smoothly.

2. **Visual alignment of the Feed ribbon with the Tape swimlanes**:
   - In the Studio, visually align the live feed visualization (ribbon) horizontally with the tape swimlanes beneath it. Currently the ribbon width and margins do not match the track bounds, making it feel visually disconnected.

3. **Unified Waveform / Clip Editor & Streamlined Edit Flow**:
   - Share the same editor controls across surfaces: editing a standalone waveform (take) should expose the same rich edit controls available on the tape reel in the Studio (e.g., fade in/out curves, gain, normalize, reverse).
   - Streamline navigation to the editor: currently reaching the waveform editor from the Listening Room is unintuitive (requires opening the sketchbook and then opening the waveform). Re-evaluate user flows to make waveform editing direct and intuitive.

4. **UI Simplification & Progressive Disclosure**:
   - Simplify the visual interface by moving secondary or infrequently used controls into clean drawers, sheets, or menus to reduce visual clutter and keep primary workflows fast.
