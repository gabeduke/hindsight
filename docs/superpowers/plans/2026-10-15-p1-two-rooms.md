# The two rooms (P1) — implementation plan

**Goal:** Make the Studio and the Listening Room real as pages, behind a
per-device flag, before any new feature: two tabs, the feed and KEEP above
the tape, and Settings at the Studio's foot.

**Spec:** `docs/superpowers/specs/2026-10-15-rooms-design.md`, *Step 1 (P1):
the two rooms as pages*

## Global Constraints

- Behind `hindsight.rooms`, this device only, off by default. With it off,
  nothing changes: no markup in the page, no listeners, no requests.
- Settings keeps exactly one route: the about line at the Studio's foot.
  Nothing hides it (`AGENTS.md`).
- No new page. The Studio grows out of `tape.html` (and is `index.html`
  with the tape off); the Listening Room is `takes.html` and `wave.html`.
- Reuse the feed's modules (`Ribbon`, `VUMeters`, `Meters`, `connectLive`,
  `initSettings`, `initUpdate`); what is Capture's own logic moves into a
  module both pages import, unchanged for Capture.
- CSS in one block at the end of `styles.css`, every selector on a class
  only the Studio's markup wears.
- `sw.js` → `v78`; every new `lib/` file in `SHELL`; `lib/rooms/` in the
  `node --test` globs of `AGENTS.md` and `ci.yml`.
- `P2`, `P5` and `P6` import `lib/rooms/flag.js`: keep it small and its API
  stable (`ROOMS_FLAG`, `on()`, `setOn()`).
