# The crate (B1) — implementation plan

**Goal:** Keep pieces of takes, the ring and the tape as clips on a crate, and
drop them on a tape, without adding takes.

**Spec:** `docs/superpowers/specs/2026-10-07-crate-design.md`

## Global Constraints

- The takes list never changes for a keep; pruning never touches the crate.
- A drop from the crate is a clipboard drop (`dropBoard`): one undo.
- The crate is a clean-up root; an unreadable one stops the clean-up.
- `sw.js` → `v42`; `TIPS` and guide §9 match.
