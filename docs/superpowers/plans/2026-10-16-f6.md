# F6 · Open as one page — implementation plan

**Goal:** With `hindsight.rooms` on, a take's page (`wave.html?file=`) is
**Open**: it opens where the bar was, ✎ arrives with a note started at the
frame that was being heard, GRAB / KEEP / notes / the tag / *From this take*
and *Earlier bounces* are on the page itself, and the chair and TOOLS are
gone. `wave.html?tape=` goes to the Studio. With the flag off, nothing changes.

**Spec:** `docs/superpowers/specs/2026-10-15-flow-design.md` — *Open: one page
to dig in*, *What happens to today's surfaces* (chair, TOOLS, `?tape=`),
*Answered by Gabe* 1 (Open is its own page) and 2 (tapes live in the Studio),
*Build order* F6. F5b review nits (STATE.md, "F5b (PR #129)" item 7).

**Branch:** `rooms/f6-open` off `rooms/all` (e28079d). PR base `rooms/all`.
`CACHE` -> `hindsight-shell-v108`. No Go.

## Decisions (the spec leaves them to the build)

- Open is the take page as it is, plus a rooms-only layer (`lib/room/open.js`)
  mounted where the chair was. The page's own waveform, selection, tempo,
  MIDI lanes and bar stay; the chair's deck, strip, sketchbook and TOOLS fold
  go. Nothing is removed from the page with the rooms off.
- A line under *From this take* / *Earlier bounces* opens that take (this
  page's bar is its own take's; it has no tap-to-play for another).
- `?tape=` redirects to `/tape.html` (the Studio holds the tape; loading it
  there is the Studio's job). `swap.js` goes with the chair.
