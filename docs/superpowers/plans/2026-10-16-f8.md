# F8: the words pass — implementation plan

**Goal:** with the rooms on, no retired word appears on a rooms page, and
the renames in the flow spec's *Every word on screen today* are made
(`docs/superpowers/specs/2026-10-15-flow-design.md`). With the rooms off the
text is byte-identical to `rooms/all`.

## Global Constraints

- A string shared by both modes is never edited. The rooms' text is chosen at
  runtime from the flag (`lib/rooms/flag.js`); only rooms-only modules are
  edited in place.
- `docs/guide.md` is F9's. Only a tips-table row may change, and only to keep
  `guideTips` parity green; any such row is named in the PR.
- `sw.js` → `hindsight-shell-v109`; new lib files go in `SHELL`.

## How

- `lib/rooms/words.js`: `say()` renames the rooms' words in developer-authored
  text (tips, static markup); `applyWords(doc)` does it once to a page's
  markup. Not applied to anything a person typed (take, tape and tag names).
- `tipFor` answers through `say()` with the rooms on.
- Strings built in JS (toasts, aria-labels, sheets) choose their wording from
  the flag where they are made.
