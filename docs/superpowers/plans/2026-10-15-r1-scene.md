# The scene contract (R1) — implementation plan

**Goal:** Give every drawn thing one shape — state the page writes, a model
that steps it on the shared ticker, a renderer that only draws — and move the
private animation loops onto that one ticker, with **no visible change**.

**Spec:** `docs/superpowers/specs/2026-10-15-scene-contract-design.md`,
*The contract (R1)* and *What R1 builds*. The render briefs R2–R7 are not
this step.

## Global Constraints

- No flag: R1 is plumbing under every page. It is judged by no visible change
  — the bench at `/objects.html`, and the takes, wave and tape pages, pixel
  for pixel, at 390×844 and 1440×900, in both schemes.
- The ticker keeps its rules: reduced motion passes `dt = Infinity`; it parks
  when no step asks for another frame.
- Only the page writes state; only models compute motion; renderers only
  draw. A renderer that writes state is an error the scene reports.
- `lib/scene/` joins the `node --test` globs in `AGENTS.md` and `ci.yml`;
  every new file joins `SHELL`; `sw.js` → `hindsight-shell-v77`.

- [ ] **Before:** capture the bench, takes, wave and tape pages on the demo
  with the clock pinned, twice, to show the captures are deterministic.
- [ ] **Ticker:** steps get `(dt, now)`; `start()` from inside a step no
  longer schedules a second frame; `Loop`, one object's loop that leaves the
  ticker when it stops wanting frames. Tests in `motion.test.js`, the
  re-entrancy one seen failing first.
- [ ] **`lib/scene/object.js`:** `SceneObject` — frozen state, `set(patch)`
  (the page's only way in, `change` only when something changed), `view`,
  `on`/`emit`.
- [ ] **`lib/scene/scene.js`:** `Scene` — `add`/`remove`/`get`/`objects`,
  `start`/`stop` on the shared ticker, `wake`, `attach` for renderers; models
  step first, then renderers draw; a renderer's `set()` throws.
- [ ] **`lib/scene/renderer.js`:** the duck-typed renderer, documented
  (`mount`, `frame`, `hit`, `twin`, `destroy`).
- [ ] **Models**, pure and tested with a fake ticker:
  - `vu`: `level`, `ref`, `peak` → the needle (`ballistic`), parks once
    settled; the same at 20 Hz and 120 Hz.
  - `reels`: `pos`, `playing`, `length`, `sampleRate`, `at` (the poll) →
    `ReelMotion`'s angles and packs; `dt = Infinity` is reduced motion.
  - `cassette`: `played`, `playing` → what the face draws.
  - `ribbon`: the ring's axis, a held span, the chosen length → what is lit,
    and where recording starts, as fractions of the width.
- [ ] **`lib/scene/dom.js`:** `DomRenderer` — a drawer per object, drawn only
  when its view or state changed or it was invalidated; `hit` by bounding box.
- [ ] **Objects onto the scene, drawing unchanged:** `VUMeters`,
  `ReelWindow`, `CassetteFace`, `Ribbon`.
- [ ] **One ticker:** `NowPlaying`, `wave/clock.js`, `wave/rising.js`,
  `wave/rowwave.js` move their loops onto it. List what
  `grep -rn requestAnimationFrame web/static` finds, and why anything is left.
- [ ] **The bench** builds scene objects and draws them with `DomRenderer`.
- [ ] `AGENTS.md`, `ci.yml` globs; `SHELL`; `sw.js` v77.
- [ ] **After:** the same captures, pixel-compared; each moved loop sampled
  over time to show it still moves, and the ticker seen parking.
- [ ] Every check in `AGENTS.md`; the PR against
  `claude/play-style-recording-redesign-f37e80`.
